A note on this build

This is a front-end demo.

Coins, as built here, is a self-contained HTML/CSS/JS interface. Prices are simulated locally, accounts and balances live only in this browser tab's memory, and nothing is persisted, transmitted, or connected to real markets or payment rails. It's meant as a interface and interaction template for a real trading product — not a live financial service.
